# Sudeep Sah — Engineering Portfolio

A responsive Node.js + Express + EJS portfolio using details from the supplied CV.

## Run locally
1. Install Node.js 18 or newer.
2. In this folder, run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.

## Deploy to Vercel
Push this folder to a GitHub repository and import it into Vercel. The project includes `vercel.json`.
Update profile content in `server.js`; page structure is in `views/index.ejs`; styles are in `public/css/style.css`; interactions are in `public/js/script.js`.

## Notes
- Contact details and personal information are included because they appeared in the supplied CV. Review what you want public before deploying.
- No percentage progress bars or fabricated skill ratings are used.
- The portfolio does not include a downloadable CV button because the original CV file should only be made public if you choose to publish it.
